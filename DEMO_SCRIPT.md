# 10-Minute Demonstration Script

## 0:00–0:45 — Introduction
Introduce TaskFlow, the problem it solves and the stack.

## 0:45–2:00 — Authentication
Register, log in, show the protected dashboard, log out and attempt direct access.

## 2:00–4:30 — CRUD
Create a project, view it, edit it, create tasks, update status/priority, and delete a task/project.

## 4:30–5:30 — Validation and feedback
Submit invalid data, show field errors, loading state and API error messages.

## 5:30–6:30 — Database and API
Show Prisma models and Swagger UI. Explain REST naming and relationships.

## 6:30–7:30 — Security
Show bcrypt, JWT middleware, ownership checks, Helmet, CORS and rate limiting.

## 7:30–8:30 — Architecture and TypeScript
Show routes/controllers/middleware separation and typed interfaces.

## 8:30–9:30 — Testing
Run backend tests, frontend component tests and Playwright tests.

## 9:30–10:00 — Accessibility and reflection
Use keyboard navigation, show labels/semantic HTML, and state future improvements.
